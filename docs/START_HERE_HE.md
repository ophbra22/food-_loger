# FoodLogger — מתחילים כאן

זהו מימוש חדש לרעיון שבתיאור שצירפת: זיהוי מזון מתמונות באמצעות Python ו־TensorFlow,
וחישוב ערכים תזונתיים לפי משקל המנה. הקוד המקורי לא שוחזר.

## מה כלול

- אפליקציה עם ממשק באנגלית שמתאים להדגמה ולשיתוף בתיק עבודות.
- זיהוי אמיתי באמצעות MobileNetV2 מאומן מראש, עם הצעות ואפשרות לתיקון ידני.
- קטלוג של 27 מזונות, מהם 23 ממופים למודל ברירת המחדל.
- חישוב קלוריות, חלבון, פחמימות ושומן לפי מספר הגרמים שהזנת.
- יומן ארוחות שנשמר ב־SQLite, מעבר בין תאריכים, מחיקה וייצוא CSV.
- API מתועד, בדיקות אוטומטיות ותהליך אימון ופיין־טיונינג למודל משלך.

## הרצה ב־Mac או Linux

יש להתקין Python 3.11 או 3.12. פתח Terminal בתוך תיקיית הפרויקט:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[ml,dev]"
foodlogger download-model
foodlogger
```

פתח בדפדפן: [http://127.0.0.1:8000](http://127.0.0.1:8000).
כדי לעצור, לחץ Ctrl+C בחלון ה־Terminal.
בהרצות הבאות מספיק להפעיל את הסביבה עם `source .venv/bin/activate` ואז `foodlogger`.

ב־Windows משתמשים ב־`python` ובפקודת הפעלה `.venv\Scripts\Activate.ps1` ב־PowerShell.
TensorFlow 2.20 מתאים ל־Mac עם Apple Silicon. ל־Intel Mac אפשר להשתמש ב־Docker,
או להריץ רק את היומן עם `python -m pip install -e ".[dev]"` ללא זיהוי תמונה.

ההתקנה הראשונה כוללת ספריות למידת מכונה ולכן עשויה להימשך מספר דקות.
הורדת משקלי המודל דורשת אינטרנט; לאחר מכן התמונות מעובדות על המחשב שמריץ את
האפליקציה, ולא נשלחות לשירות זיהוי חיצוני. אין צורך במפתח API או בכרטיס מסך.

## ההדגמה הראשונה

1. העלה תמונה ברורה של מזון יחיד, למשל בננה או פיצה.
2. בדוק את הזיהוי. אם הוא שגוי או אינו בטוח, בחר את המזון מהרשימה.
3. הזן את המשקל בגרמים ובחר ארוחה.
4. הוסף ליומן וראה כיצד הסיכום היומי משתנה.
5. רענן את העמוד כדי להראות שהמידע נשמר, ועבור לתאריך אחר.
6. הצג גם את [תיעוד ה־API](http://127.0.0.1:8000/docs).

אין דרך להסיק משקל מדויק מתמונה רגילה. ערכי התזונה המצורפים הם אומדנים
להדגמה, ואינם מאגר תזונתי מאומת. המודל המוכן מזהה קטגוריות ImageNet מוגבלות;
הוא לא מאומן במיוחד על כל המנות האפשריות ולא מפרק צלחת למרכיבים.

## איך להציג בקורות חיים

ניסוח שמבוסס על המימוש הקיים:

> **FoodLogger — Python, TensorFlow, FastAPI, SQLite:** פיתוח אפליקציה לזיהוי מזון
> מתמונות ולניהול יומן תזונה, בשילוב מודל מאומן מראש, חישוב ערכים תזונתיים לפי
> משקל מנה, REST API ובדיקות אוטומטיות. מימוש תהליך Transfer Learning, פיין־טיונינג
> והערכת מודלים על סט בדיקה נפרד.

כדי שתוכל להסביר את הפרויקט בביטחון, קרא את [מדריך הראיון](INTERVIEW.md),
הרץ אותו בעצמך, ושנה או הרחב חלק שאתה מבין. אל תוסיף אחוזי דיוק או טענה שאימנת
מודל על Food-101 עד שביצעת את האימון ומדדת את התוצאות. ההוראות המלאות נמצאות
ב־[README](../README.md), כולל הפעלת מודל מותאם אישית.

## איפה הנתונים והקוד

היומן נשמר בקובץ `runtime/journal.sqlite3` בתוך תיקיית ההרצה. שמור אותו אם תרצה
להעביר את היומן. התמונות שהעלית אינן נשמרות. הקוד נמצא ב־`src/foodlogger`,
והבדיקות ב־`tests`. הרץ `pytest` מתוך הסביבה הווירטואלית לבדיקת הפרויקט.

להעלאה ל־GitHub: צור מאגר בשם FoodLogger והעלה את קוד הפרויקט. אין להעלות את
`.venv`, את מסד הנתונים, את מערך התמונות או משקלים גדולים; `.gitignore` כבר מכסה
אותם. קובץ ה־ZIP מכיל קוד ותיעוד, ללא מידע אישי וללא ספריות ההתקנה.
