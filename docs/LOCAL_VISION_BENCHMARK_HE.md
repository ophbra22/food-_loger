# מדידת זיהוי תמונות על המחשב הישן

מטרת הבדיקה היא למדוד את המחשב עצמו: i7-8565U, זיכרון 16GB וכרטיס MX250 עם
2GB זיכרון גרפי. לא הרצנו עליו עדיין בדיקה. אין להסיק מהתוצאות על ה־Mac
כמה זמן ייקח למחשב הזה. מדובר בהרצת מודל קיים, לא באימון מודל חדש מאפס.

## הכנה חד־פעמית

1. התקן את Ollama מהאתר הרשמי: https://ollama.com/download/windows .
2. התקן Python 3.11 או 3.12 והעתק למחשב את תיקיית הפרויקט המעודכנת,
   כולל `evaluations/meal_analysis`. אין צורך להעתיק `.env`, מפתחות API,
   חשבונות, יומן אישי או תיקיות `runtime`, `.venv` ו־`node_modules`.
3. פתח PowerShell בתיקיית הפרויקט והריץ:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
ollama pull qwen3-vl:4b-instruct
```

הורדת המודל היא כ־3.3GB. אין חיוב API; יש צריכת חשמל ותעבורת אינטרנט.
הוראות Ollama: https://docs.ollama.com/windows .

## מדידה

השאר את Ollama פועל, חבר את המחשב לחשמל וסגור תוכנות כבדות. אל תפתח פורט
באינטרנט לצורך הבדיקה. באותו חלון PowerShell:

```powershell
$env:FOODLOGGER_ENV = "development"
$env:FOODLOGGER_VISION_PROVIDER = "ollama"
$env:FOODLOGGER_VISION_MODEL = "qwen3-vl:4b-instruct"
$env:FOODLOGGER_OLLAMA_URL = "http://127.0.0.1:11434"
.\.venv\Scripts\python.exe scripts/evaluate_meal_analysis.py --mode vision --interval-seconds 0 --output evaluations/meal_analysis/old-pc-run-1.json
```

הרץ שוב עם `old-pc-run-2.json`, ובפעם שלישית עם `old-pc-run-3.json`.
כל הרצה פותחת תהליך חדש, ולכן אינה משתמשת במטמון תוצאות של ההרצה הקודמת.
המודל עשוי להישאר בזיכרון; זמן התמונה הראשונה אינו בהכרח זמן התנעה קרה.
לבדיקת התנעה קרה עצור את המודל באמצעות `ollama stop qwen3-vl:4b-instruct`
לפני הרצה נפרדת ותעד זאת בשם הקובץ.

הדוח כולל זמן לכל תמונה, ממוצע, זיהויים שהצליחו, רכיבים חסרים, זיהויים שגויים
ושגיאות משקל מול נתוני המחקר. בזמן ההרצה פתח מנהל המשימות → ביצועים ותעד
את צריכת הזיכרון והמעבד ואת הזיכרון הגרפי. `ollama ps` מציג אם החישוב
משתמש ב־CPU, ב־GPU או בשניהם. אין להניח ש־2GB מספיקים לכל המודל וההקשר.

שלח את קובצי הדוח בלבד כדי שנוכל להשוות. אם מתקבל timeout, זו תוצאה חשובה
ולא הצלחה: המתאם מגביל המתנה ל־100 שניות לפעולת קריאה. הדוח אינו בודק
משתמשים במקביל, רשת סלולרית, התחממות במשך יממה או זמינות של שרת ביתי.

בדיקת ביצועים אינה מפרסמת שרת ואינה מחברת אליו את אפליקציית הייצור.
